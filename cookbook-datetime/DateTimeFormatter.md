## 1. 紧凑型（无分隔符）

| 格式                | 示例（假设时间为 2026-09-01 16:18:15.480 +08:00） |
| :------------------ | :------------------------------------------------ |
| `yyyyMMddHHmmssSSS` | `20260901161815480`                               |
| `yyMMddHHmmssSSS`   | `260901161815480`                                 |
| `yyyyMMddHHmmss`    | `20260901161815`                                  |
| `yyMMddHHmmss`      | `260901161815`                                    |

## 2. 标准日期时间（连字符分隔）

| 格式                      | 示例                   |
| :------------------------ | :------------------------ |
| `yyyy-MM-dd HH:mm:ss.SSS` | `2026-09-01 16:18:15.480` |
| `yyyy-MM-dd HH:mm:ss`     | `2026-09-01 16:18:15`     |
| `yyyy-MM-dd`              | `2026-09-01`              |

## 3. 斜杠分隔日期时间

| 格式                      | 示例                      |
| :------------------------ | :------------------------ |
| `yyyy/MM/dd HH:mm:ss.SSS` | `2026/09/01 16:18:15.480` |
| `yyyy/MM/dd HH:mm:ss`     | `2026/09-01 16:18:15`     |
| `yyyy/MM/dd`              | `2026/09/01`              |

## 4. 纯时间（无日期）

| 格式           | 示例           |
| :------------- | :------------- |
| `HH:mm:ss.SSS` | `16:18:15.480` |
| `HH:mm:ss`     | `16:18:15`     |

## 5. 带时区偏移（ISO 8601，如 `+08:00`）

> 使用 `XXX` 表示时区偏移（`±HH:mm`），`T` 为日期时间分隔符。

| 格式                           | 示例                            |
| :----------------------------- | :------------------------------ |
| `yyyy-MM-dd'T'HH:mm:ss.SSSXXX` | `2026-09-01T16:18:15.480+08:00` |
| `yyyy-MM-dd'T'HH:mm:ssXXX`     | `2026-09-01T16:18:15+08:00`     |
| `yyyy/MM/dd'T'HH:mm:ss.SSSXXX` | `2026/09/01T16:18:15.480+08:00` |
| `yyyy/MM/dd'T'HH:mm:ssXXX`     | `2026/09/01T16:18:15+08:00`     |
| `HH:mm:ss.SSSXXX`              | `16:18:15.480+08:00`            |
| `HH:mm:ssXXX`                  | `16:18:15+08:00`                |

## 6. UTC Zulu 时区（零时区，用 `'Z'` 表示）

> 表示 UTC 时间，`Z` 为字面量。

| 格式                           | 示例（UTC时间）            |
| :----------------------------- | :------------------------- |
| `yyyy-MM-dd'T'HH:mm:ss.SSS'Z'` | `2026-09-01T08:19:07.142Z` |
| `yyyy-MM-dd'T'HH:mm:ss'Z'`     | `2026-09-01T08:19:07Z`     |
| `yyyy/MM/dd'T'HH:mm:ss.SSS'Z'` | `2026/09/01T08:19:07.142Z` |
| `yyyy/MM/dd'T'HH:mm:ss'Z'`     | `2026/09/01T08:19:07Z`     |
| `HH:mm:ss.SSS'Z'`              | `08:19:07.142Z`            |
| `HH:mm:ss'Z'`                  | `08:19:07Z`                |

## 7. ZonedDateTime（带时区ID和偏移）

> 格式：日期时间 + 偏移（`XXX`） + 方括号内时区ID（`VV`，如 `Asia/Shanghai`）。

| 格式                                   | 示例                                             |
| :------------------------------------- | :----------------------------------------------- |
| `yyyy-MM-dd HH:mm:ss.SSS XXX '['VV']'` | `2026-09-01 16:21:34.696 +08:00 [Asia/Shanghai]` |
| `yyyy-MM-dd HH:mm:ss XXX '['VV']'`     | `2026-09-01 16:21:34 +08:00 [Asia/Shanghai]`     |
| `yyyy/MM/dd HH:mm:ss.SSS XXX '['VV']'` | `2026/09/01 16:21:34.696 +08:00 [Asia/Shanghai]` |
| `yyyy/MM/dd HH:mm:ss XXX '['VV']'`     | `2026/09/01 16:21:34 +08:00 [Asia/Shanghai]`     |

**备注：**

- 毫秒部分 `SSS` 通常为3位，若需6位可写作 `SSSSSS`，但上述格式均以 `SSS` 表示。
- 所有示例时间均为示意，实际解析时请根据具体场景调整。
- 格式中的单引号（如 `'T'`、`'Z'`、`'['`、`']'`）表示字面量字符，非变量。
